# Sokoun: Your Serene Space

Projet : Plateforme de Santé Mentale "Sokoun" (سكون)

Rôle : Tu es un expert en UX/UI design spécialisé dans les applications de bien-être. Améliore mon code HTML actuel pour en faire une application React moderne, utilisant Tailwind CSS et Framer Motion pour les animations.

Instructions de Design :

Esthétique : Style "Minimaliste Thérapeutique". Utilise des coins très arrondis, des ombres douces et une palette de couleurs apaisante (Lavande, Sauge, Blanc chaud).

Typographie : Garde 'Tajawal' pour l'Arabe et utilise 'Geist' ou 'Inter' pour le Français/Anglais pour un look plus Tech/Moderne.

Animations : Ajoute des transitions fluides (fade-in, gentle slide) lors du défilement pour ne pas brusquer l'utilisateur.

Améliorations de Structure :

Header : Rends-le collant (sticky) avec un effet de flou (backdrop-blur) plus prononcé.

Section Hero : Ajoute une illustration vectorielle abstraite et douce ou un élément interactif (comme un cercle qui respire lentement) pour symboliser la sérénité.

Système de Réservation : Ne te contente pas de texte. Crée des "Cartes de Praticiens" interactives avec : photo de profil, spécialités (tags), prix et un bouton "Réserver".

Section Blog : Crée une grille de cartes modernes avec des images de couverture douces pour les articles.

Support d'Urgence : Ajoute un bouton d'urgence "Aide immédiate" flottant ou très distinct qui ouvre une modal avec les numéros de secours en Tunisie.

Technique :

Assure une gestion parfaite du RTL (Arabe) et LTR (Français).

Utilise des icônes de la bibliothèque 'Lucide-React' pour un aspect plus fin.

Le site doit être ultra-rapide et optimisé pour le mobile (usage prioritaire des jeunes).

Contenu à intégrer : (Utilise les textes de mon code HTML fourni pour garder l'esprit du projet "Sokoun" : sérénité et tranquillité pour les 18+).
